# قبول المرحلة الثانية — إدارة الأصناف والتصنيفات والوحدات والباركود

## النطاق المنفذ
- كيان وحدات قياس مستقل مع اسم ورمز فريدين، وبذور أولية عامة قابلة للتعديل لاحقاً.
- إضافة وصف للتصنيف مع المحافظة على التصنيفات القديمة.
- ربط اختياري بين الصنف ووحدة القياس مع إبقاء حقل الوحدة النصي للتوافق.
- ترحيل Alembic رقم 0002 مع ترحيل بيانات الوحدات وربط وحدات المنتجات الحالية تلقائياً عند التطابق.
- إنشاء الأصناف والتحقق من الرمز والاسم والأسعار والكميات وحد إعادة الطلب.
- إسناد التصنيف والوحدة والتحقق من نشاطهما.
- بحث موحد بالاسم والرمز والباركود، وقراءة مباشرة بواسطة الباركود.
- تعديل بيانات الصنف وإيقافه منطقياً دون حذف السجل.
- واجهة عربية RTL للبحث والإضافة والتعديل وإيقاف الصنف وإضافة التصنيفات والوحدات.

## حدود صريحة
- لا تتضمن هذه المرحلة حركة المخزون والجرد؛ ذلك ضمن المرحلة الثالثة.
- لا يوجد تكامل مع قارئ باركود مادي أو طباعة ملصقات حتى الآن؛ حقل الباركود والبحث به جاهزان على مستوى البيانات والخدمة.
- لا تُنشأ بيانات أصناف تجارية حقيقية تلقائياً؛ قاعدة العميل تبدأ بكتالوج فارغ والوحدات الافتراضية فقط.
- لا تعتبر المرحلة نظام نقاط بيع أو مخزوناً تجارياً مكتملاً.

# المرحلة الثانية — دليل الأصناف والتصنيفات والوحدات والباركود

**الحالة: قيد التنفيذ — لم تعتمد المرحلة نهائياً بعد.**

## النطاق الوظيفي
- تصنيفات هرمية برموز فريدة ووصف وتفعيل/إيقاف دون حذف السجلات المرتبطة.
- وحدات قياس مستقلة برمز واختصار ودقة كمية من صفر إلى ثلاث خانات عشرية.
- دليل أصناف برمز مخزني واسم وتصنيف ووحدة وأسعار ورصيد افتتاحي وحد تنبيه وملاحظات.
- باركود أساسي وباركودات بديلة متعددة مع منع التكرار دون حساسية لحالة الأحرف.
- البحث بالاسم أو الرمز أو أي باركود، والتصفية بالتصنيف.
- تعديل بيانات الصنف وأرشفته دون حذف تاريخي.
- ترحيل يحافظ على البيانات السابقة وينقل الباركودات القديمة إلى سجل مستقل.

## حدود البيانات
كل بيانات الاختبارات والأمثلة تجريبية. لا توجد بيانات أصناف حقيقية لعميل حتى يقدمها صاحب المنشأة أو تُستورد من ملف موثوق.

## قرار الإغلاق
تبقى المرحلة الثانية قيد التنفيذ حتى إغلاق البوابات المفتوحة أعلاه. لا تُدمج إلى main ولا يبدأ تنفيذ المرحلة الثالثة قبل اعتماد المرحلة الثانية صراحةً.

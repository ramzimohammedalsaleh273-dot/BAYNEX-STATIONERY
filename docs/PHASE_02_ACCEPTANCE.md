# المرحلة الثانية — دليل الأصناف والتصنيفات والوحدات والباركود

**الحالة: قيد التنفيذ — لا تُعلن مكتملة قبل نجاح جميع بوابات القبول.**

## النطاق الوظيفي
- تصنيفات هرمية برموز فريدة ووصف وتفعيل/إيقاف دون حذف السجلات المرتبطة.
- وحدات قياس مستقلة برمز واختصار ودقة كمية من صفر إلى ثلاث خانات عشرية.
- دليل أصناف برمز مخزني واسم وتصنيف ووحدة وأسعار ورصيد افتتاحي وحد تنبيه وملاحظات.
- باركود أساسي وباركودات بديلة متعددة مع منع التكرار دون حساسية لحالة الأحرف.
- البحث بالاسم أو الرمز أو أي باركود، والتصفية بالتصنيف.
- تعديل بيانات الصنف وأرشفته دون حذف تاريخي.
- ترحيل يحافظ على البيانات السابقة وينقل الباركودات القديمة إلى سجل مستقل.

## بوابات القبول الإلزامية
- [ ] ترقية قاعدة قديمة من 0001_initial إلى 0002_catalog مع الاحتفاظ بالبيانات.
- [ ] إنشاء قاعدة جديدة والوصول إلى أحدث إصدار ترحيل.
- [ ] منع تكرار الرموز والباركودات حتى مع اختلاف حالة الأحرف.
- [ ] رفض الأسعار والكميات السالبة والقيم غير المحدودة والدقة الزائدة.
- [ ] اختبار التصنيفات الأب/الابن وإيقاف التصنيف.
- [ ] اختبار الوحدات ودقتها.
- [ ] اختبار الباركود الأساسي والبديل والبحث عنهما.
- [ ] اختبار تعديل الصنف وأرشفته والبحث والتصفية.
- [ ] اختبار واجهة RTL وحفظ الصنف والبحث وإعادة التحميل.
- [ ] نجاح Ruff وpytest على Linux وWindows وبناء الحزمة وتثبيتها في بيئة معزولة.

## حدود البيانات
كل بيانات الاختبارات والأمثلة تجريبية. لا توجد بيانات أصناف حقيقية لعميل حتى يقدمها صاحب المنشأة أو تُستورد من ملف موثوق.

## قرار الإغلاق
يُحدّث هذا التقرير بالأدلة الفعلية بعد تشغيل CI. لا تُحوّل حالة المرحلة إلى مكتملة ولا تُدمج إلى main إذا بقي اختبار أو ترحيل أو وظيفة دون إثبات.

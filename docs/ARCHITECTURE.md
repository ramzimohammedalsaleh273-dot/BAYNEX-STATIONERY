# المعمارية الأولية

## النمط

تطبيق مكتبي محلي أولاً (Offline-first)، بواجهة PySide6، ومنطق أعمال مستقل عن الواجهة، وطبقة وصول بيانات عبر SQLAlchemy، وقاعدة SQLite على جهاز العميل.

## الطبقات

1. واجهة المستخدم: العرض وإدخال الأوامر فقط.
2. الخدمات: حالات الاستخدام والمعاملات والتحقق.
3. المجال: قواعد المال والتسعير والمخزون دون اعتماد على Qt.
4. البيانات: نماذج ORM والجلسات والقيود وترحيلات Alembic.
5. البنية التشغيلية: إعدادات محلية، سجلات، نسخ احتياطية وتحديثات (لم تنفذ جميعها بعد).

## دفتر المخزون — المرحلة الثالثة

- سجل `stock_movements` هو مصدر الحقيقة لأرصدة الأصناف.
- كل حركة مرتبطة بصنف ومستودع وكمية موقعة وسبب ومرجع وتاريخ.
- رصيد الصنف في مستودع = مجموع كميات الحركات لذلك الصنف والمستودع.
- حقل `products.stock_quantity` باقٍ مؤقتاً للتوافق كإجمالي مشتق، ولا يجوز استخدامه لإنشاء حركة مخزون أو تعديله يدوياً.
- البيع والإدخال والصرف والجرد والتحويل تستخدم خدمة دفتر الحركات.
- الحركات المسجلة غير قابلة للتعديل أو الحذف عبر ORM؛ التصحيح بحركة جديدة موثقة.
- التحويل مستند واحد يولد حركتي صرف وإيداع داخل معاملة واحدة.
- الجرد يحتفظ بلقطة الرصيد الدفتري والكمية الفعلية والفرق، ولا يغيّر الرصيد قبل الترحيل. يرفض الترحيل إذا تغيرت أرصدة اللقطة أو قائمة الأصناف بعد بدء الجرد.
- ترحيل 0003 يضيف المستودع الافتراضي ويحوّل الرصيد السابق إلى حركة افتتاحية محسوبة بعد احتساب الحركات القديمة، لمنع تكرار خصم المبيعات التاريخية.

## مبادئ إلزامية

- لا تنفذ الواجهة SQL أو تعدل قاعدة البيانات مباشرة.
- كل عملية مالية أو مخزنية متعددة السجلات يجب أن تكون ذرية داخل معاملة واحدة.
- استخدام Decimal للمال والكميات القابلة للكسور.
- لا تحذف المستندات المرحلة؛ تستخدم مستندات عكسية أو تسويات جديدة مع سبب ومستخدم وتاريخ عند اكتمال نظام المستخدمين.
- لا تعدل المخزون بتغيير رصيد الصنف مباشرة؛ الرصيد يصبح ناتجاً عن الحركات.
- كل عميل/منشأة يجب أن تكون بياناته معزولة.
- ترحيلات قاعدة البيانات تكون بإصدارات Alembic قبل أي إصدار إنتاجي.
- لا تحفظ كلمات المرور كنص صريح، ولا تعتبر إخفاء الزر صلاحية أمنية.
- لا تضع أسراراً أو بيانات عملاء في Git.

## ملاحظة

هذه معمارية تأسيسية متطورة وليست بعد مخططاً نهائياً أو ضماناً للامتثال المحاسبي أو الضريبي. ما زالت المشتريات وPOS الكاملة والمحاسبة والصلاحيات والنسخ الاحتياطي والتسليم التجاري خارج النطاق المنجز.

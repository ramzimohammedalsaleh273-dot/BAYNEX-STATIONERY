# حالة مشروع BAYNEX STATIONERY

**آخر مرحلة منفذة في هذا الفرع: المرحلة التاسعة — الخزينة والصناديق والبنوك.**

## المراحل المنفذة في سلسلة هذا الفرع

- المرحلة 01: التأسيس التقني وهيكل التطبيق وقاعدة البيانات.
- المرحلة 02: دليل الأصناف والتصنيفات والوحدات والباركود والتسعير.
- المرحلة 03: المستودعات ودفتر حركات المخزون والجرد والتحويلات.
- المرحلة 04: أساس الواجهات العربية RTL ومكونات الجداول والأدوات المشتركة.
- المرحلة 05: فواتير المبيعات وترحيلها وربطها بخصم المخزون وتسجيل الدفعات.
- المرحلة 06: شاشة POS على نمط مستند ERP، مع تسعير التجزئة والجملة، حفظ واستعادة الفواتير المعلقة، الدفعات الجزئية والمجزأة، المرتجعات وسجل نشاط الكاشير.
- المرحلة 07: الموردون وفواتير المشتريات والدفعات وترحيل الوارد إلى المخزون وتحديث متوسط التكلفة.
- المرحلة 08: دليل الحسابات وقيود اليومية المزدوجة وميزان المراجعة وكشف حركة الحساب.
- المرحلة 09: حسابات الصناديق والبنوك، الأرصدة الافتتاحية، سندات القبض والصرف والتحويل الداخلي، وربطها بقيود يومية متوازنة.

## ما لا يزال غير مكتمل — لا تعتبر النسخة جاهزة للبيع

- لم تُجرَ معاينة يدوية كاملة لكل الشاشات على جهاز المستخدم بعد هذا الفرع.
- تم ربط ترحيل فواتير المبيعات والمشتريات والمرتجعات بقيود يومية مزدوجة تلقائية، مع حساب الإيراد والضريبة وتكلفة البضاعة ومردوداتها.
- أضيف حفظ تكلفة الوحدة التاريخية على سطر البيع بترحيل قاعدة البيانات `0010_sale_cost_snapshot`.
- تُربط الدفعات بدفتر الصندوق/البنك تلقائياً عندما يوجد حساب نشط وحيد يطابق طريقة الدفع؛ عند غياب الحساب أو تعدده يستخدم النظام حساب تسوية لتجنب اختيار حساب خاطئ.
- لا يزال دفتر العملاء والموردين إجمالياً، ولا يوجد دفتر فرعي مستقل لكل عميل/مورد أو أعمار ديون وتسويات تفصيلية.
- لا توجد إدارة مكتملة للمستخدمين والأدوار والصلاحيات.
- لا توجد إدارة فترات مالية وإقفال سنة مالية أو تسويات ضريبية معتمدة.
- لا توجد تسوية بنكية أو استيراد كشوف البنوك.
- لا تزال النسخ الاحتياطي والاستعادة، والطباعة الحرارية وملصقات الباركود، والمثبت التنفيذي EXE والتحديثات بحاجة إلى تنفيذ واختبار.
- قاعدة SQLite الحالية محلية لجهاز واحد؛ لا تستخدمها كقاعدة متعددة المستخدمين عبر شبكة.
- لا تستخدم النظام بعد لإدارة أموال أو مخزون منشأة حقيقية قبل إغلاق بوابات الجودة والقبول التشغيلي.

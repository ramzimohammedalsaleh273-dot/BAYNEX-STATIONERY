# حالة مشروع BAYNEX STATIONERY

**المرحلة الحالية: المرحلة الثالثة — المخزون والجرد والمستودعات وحركات المخزون.**

## الحالة الدقيقة

- المرحلة الأولى: مكتملة ضمن نطاق التأسيس التقني المعتمد.
- المرحلة الثانية: مقبولة يدوياً من المستخدم على Windows؛ أكد نجاح إضافة التصنيف والوحدة والصنف والبحث بالباركود والتعديل والإيقاف.
- المرحلة الثالثة: تنفيذ الكود والترحيل والاختبارات الآلية مكتمل؛ القبول اليدوي النهائي على Windows ما زال مطلوباً.
- النظام ليس ERP تجارياً نهائياً ولا يجوز استخدامه بعد لإدارة أموال أو مخزون منشأة حقيقية قبل إغلاق جميع المراحل والبوابات التشغيلية.

## المرحلة الثالثة — ما تم تنفيذه

- مستودع افتراضي، وإنشاء وتعديل وتفعيل وإيقاف المستودعات، مع منع إيقاف الافتراضي أو مستودع ذي رصيد.
- دفتر حركات مخزون مرتبط بالصنف والمستودع والمرجع والسبب والتاريخ.
- الأرصدة حسب المستودع مشتقة من مجموع الحركات.
- إدخال وصرف مع منع الرصيد السالب افتراضياً ودقة حتى ثلاث خانات عشرية.
- تحويل بين مستودعين عبر مستند واحد وحركتي صرف وإيداع ضمن معاملة واحدة.
- جرد مستودع شامل بلقطة دفترية وكمية فعلية وفروق، مع تأكيد قبل الترحيل ومنع الترحيل المكرر أو اللقطة المتقادمة.
- الحركات المسجلة محمية من التعديل والحذف عبر ORM.
- ربط البيع بالمستودع المختار وتسجيل الخصم في دفتر الحركات.
- واجهة Windows عربية RTL لإدارة المستودعات والإدخال والصرف والتحويل والجرد وسجل الحركات.
- ترحيل Alembic `0003_inventory` يحافظ على أرصدة المنتجات وحركات المبيعات التاريخية دون إعادة احتساب خصوماتها مرتين.

## الاختبارات الآلية

- اختبارات الأرصدة والإدخال والصرف ورفض الرصيد غير الكافي.
- اختبارات التحويل والجرد والتسويات ومنع التكرار.
- اختبارات ثبات حركات المخزون وسلامة قائمة الأصناف وقت الجرد.
- اختبارات الترقية من قاعدة المرحلة الأولى والثانية والحفاظ على الرصيد والحركة التاريخية.
- Ruff وpytest وبناء Wheel والتثبيت المعزول على Windows وLinux؛ راجع آخر تشغيل CI المرتبط بالفرع.

## الحدود المتبقية

- تجربة Windows اليدوية للمرحلة الثالثة لم يؤكدها المستخدم بعد.
- لا يوجد تكامل مع قارئ باركود أو طابعة ملصقات.
- لا توجد مشتريات وموردون ومرتجعات شراء بعد.
- لا توجد POS مكتملة أو محاسبة عامة أو صلاحيات نهائية أو نسخ احتياطي وتسليم EXE.
- قاعدة SQLite الحالية مخصصة للعمل المحلي؛ لا تعتبرها قاعدة متعددة المستخدمين عبر الشبكة.
- لا توجد بيانات أصناف تجارية حقيقية مقدمة من منشأة.

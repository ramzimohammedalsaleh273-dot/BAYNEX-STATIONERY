## المرحلة الثانية — ما نُفذ حتى الآن

- إضافة ترحيل قاعدة البيانات 0002_catalog مع وحدات القياس وسجل مستقل للباركودات البديلة.
- تحويل التصنيفات إلى بنية هرمية، وإضافة الرمز والوصف وحالة التفعيل.
- إنشاء سجل وحدات برمز واسم واختصار ودقة كمية من صفر إلى ثلاث خانات عشرية.
- ربط كل صنف بوحدة معرفة إلزامياً، مع تطبيق دقة الوحدة على الرصيد وحد التنبيه.
- توسيع دليل الأصناف: التصنيف، الوحدة، الأسعار، الرصيد الافتتاحي، حد التنبيه والملاحظات.
- إضافة خدمات البحث بالاسم والرمز والباركود الأساسي والبديل، ومنع التكرار دون حساسية لحالة الأحرف.
- إضافة خدمات تعديل الصنف وأرشفته وإضافة باركودات بديلة.
- واجهة عربية RTL لإضافة الأصناف والتصنيفات والوحدات، والبحث في الدليل.
- إضافة اختبارات لترقية قاعدة قديمة مع الحفاظ على الأصناف والتصنيفات والباركودات، واختبارات التصنيفات والوحدات والباركودات ودقة الكميات.

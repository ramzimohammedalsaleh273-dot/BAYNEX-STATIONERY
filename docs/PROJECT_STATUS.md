# حالة مشروع BAYNEX STATIONERY

آخر تحديث: 2026-11-10

## ما تم إنشاؤه في مرحلة التأسيس

- مشروع Python قابل للتثبيت مع تعريف الاعتماديات.
- واجهة سطح مكتب باستخدام PySide6 واتجاه من اليمين إلى اليسار.
- قاعدة SQLite محلية.
- نموذج أولي للأصناف والتصنيفات.
- خدمة فعلية لإضافة الأصناف وعرضها من قاعدة البيانات.
- طبقة خلفية أولية لترحيل فاتورة بيع والتحقق من توفر المخزون وتسجيل الدفع وحركة الصنف ضمن معاملة يملكها المستدعي.
- اختبارات أولية لترحيل البيع وحماية الرصيد من البيع فوق المتاح.
- قواعد حسابية أولية تستخدم Decimal لتجنب أخطاء الأعداد العشرية.
- اختبارات آلية لقواعد التسعير.
- سير عمل GitHub Actions لتشغيل الفحوصات.

## ما لم يكتمل بعد — لا تعتبره متاحاً

- واجهة نقطة البيع الكاملة وسلة المبيعات والمرتجعات وعكس الفواتير. توجد حالياً خدمة خلفية أولية لترحيل البيع فقط.
- المشتريات والموردون والعملاء.
- حركات المخزون والجرد والتحويلات والتسويات.
- الخدمات المكتبية وأوامر التشغيل والتكاليف.
- شجرة الحسابات والقيود اليومية والترحيل المحاسبي والإقفال.
- الضرائب والفوترة الإلكترونية حسب الولاية القانونية.
- المستخدمون والأدوار والصلاحيات وسجل التدقيق.
- التقارير والطباعة وقوالب الفواتير.
- النسخ الاحتياطي والاستعادة والتحقق من سلامة النسخ.
- قاعدة ترحيلات Alembic وإدارة إصدارات المخطط.
- اختبارات تكامل وقبول واختبارات واجهة المستخدم.
- بناء مثبت Windows والتوقيع الرقمي والتحديثات.

## ملاحظة البيانات

لا توجد بيانات عملاء أو أصناف حقيقية مقدمة من منشأة فعلية. قاعدة البيانات تبدأ فارغة. أي بيانات ستضاف لاحقاً لأغراض العرض يجب وسمها صراحة بأنها بيانات تجريبية، ولا يجوز تقديمها كبيانات تجارية حقيقية.

## معيار إعلان الجاهزية

لن يوصف النظام بأنه جاهز للبيع قبل اجتياز اختبارات الوظائف والتكامل والمحاسبة والمخزون والصلاحيات والنسخ والاستعادة والطباعة، واختبار تشغيل فعلي على Windows مع مستخدم تجريبي، ثم اختبار قبول موثق.


## حالة المرحلة الأولى — 2026-11-10

المرحلة الأولى ما زالت **قيد التنفيذ وليست مغلقة**. نجح سير GitHub Actions رقم `42899708174` على Linux وWindows: فحص Ruff، و17 اختبار pytest على كل نظام، وبناء Wheel والتحقق من احتواء الحزمة على ملفات ترحيل Alembic.

ما زال مطلوباً قبل إغلاق المرحلة:
- تثبيت الحزمة المبنية في بيئة نظيفة وتشغيل نقطة الدخول من الحزمة المثبتة.
- اختبار يدوي على جهاز Windows 10/11 فعلي، وليس فقط عامل CI مستضاف.
- اختبار نسخ احتياطي واستعادة لقاعدة بيانات فعلية، بعد إنشاء قاعدة اختبار مستقلة.
- إكمال مراجعة الأمان الأساسية.

نقطة الحفظ الحالية: الفرع `backup/phase-01-latest-2026-11-10`، وقد تمت مقارنته بفرع التطوير وكانت النتيجة `identical`. لا تنتقل المرحلة التالية قبل إغلاق جميع البنود أعلاه وتوثيق أدلتها.

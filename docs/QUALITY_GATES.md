- [ ] بدء التشغيل والعمل دون اتصال بعد التثبيت.
- [ ] ترحيلات قاعدة البيانات واختبار الترقية والاستعادة.
- [ ] اختبار المعاملات والتزامن وسلامة SQLite.
- [ ] اختبار الصلاحيات داخل الخدمات.
- [ ] مطابقة أرصدة المخزون مع دفتر الحركات.

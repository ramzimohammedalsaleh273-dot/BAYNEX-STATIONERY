# مراجعة أمنية أولية — المرحلة الأولى

**الحالة: مراجعة تأسيسية وليست اعتماداً أمنياً للإنتاج.**

## النطاق

مراجعة المصدر الحالي في فرع `work/foundation-2026-11-10`، وتشمل الإعدادات، واتصال SQLite، وترحيلات Alembic، وخدمات الأصناف والمبيعات والنسخ الاحتياطي، وواجهة سطح المكتب.

## ضوابط موجودة في النواة

- لا توجد كلمات مرور أو مفاتيح API أو بيانات اعتماد ثابتة في ملفات النواة التي تمت مراجعتها.
- عمليات قاعدة البيانات تمر عبر SQLAlchemy ORM، ولا تُنشأ استعلامات SQL من مدخلات المستخدم في خدمات الأصناف والمبيعات.
- تفعيل `PRAGMA foreign_keys=ON` لاتصال SQLite.
- ترحيلات قاعدة البيانات محددة بإصدارات Alembic.
- التحقق من القيم المالية غير المحدودة مثل NaN وInfinity، والتحقق من دقة الكميات الافتتاحية.
- وظائف النسخ والاستعادة تستخدم SQLite backup API، وتتحقق من سلامة النسخة، ثم تستبدل الملف ذرياً.
- اختبارات النسخ والاستعادة تتحقق من أن النسخة الفاسدة لا تستبدل قاعدة البيانات الأصلية.

## المخاطر والقيود المعروفة

| المستوى | الملاحظة | الإجراء المطلوب قبل الاستخدام التجاري |
|---|---|---|
| حرج بالنسبة للإنتاج | لا توجد مصادقة مستخدمين أو صلاحيات أو سجل تدقيق في هذا الإصدار | تنفيذ حسابات المستخدمين والأدوار والتحقق من الصلاحيات داخل الخدمات قبل فتح وظائف التشغيل |
| مرتفع | SQLite لا يطبق أقفال الصفوف التي يعتمد عليها `with_for_update`؛ لذلك لا يجوز اعتبار خدمة البيع الحالية آمنة للتزامن متعدد المستخدمين | تصميم آلية حجز/تحديث مخزون ذرية واختبار التزامن أو اختيار قاعدة بيانات خادمية عند تعدد المستخدمين |
| مرتفع | رصيد الصنف يُحدّث مباشرة، بينما سجل الحركة يسجل منفصلاً؛ كما أن الرصيد الافتتاحي لا يولّد حركة افتتاحية بعد | جعل دفتر حركات المخزون مصدر الحقيقة وإضافة حركات افتتاحية وتسويات ومطابقة أرصدة |
| متوسط | `StockMovement.reference_id` ليس مفتاحاً أجنبياً إلى مستند محدد بسبب تعدد أنواع المراجع | تصميم مراجع مستندية صريحة وقيود تكامل مناسبة |
| متوسط | قاعدة SQLite المحلية غير مشفرة على مستوى التطبيق | تحديد نموذج حماية البيانات وإدارة صلاحيات ملفات نظام التشغيل، ثم تقييم تشفير قاعدة البيانات عند الحاجة |
| متوسط | النسخ والاستعادة متاحان كخدمة برمجية مختبرة، لكن لا توجد شاشة نسخ احتياطي أو سياسة جدولة/احتفاظ أو سجل عمليات في الواجهة | دمجها لاحقاً في إعدادات النظام مع تأكيدات وسجل ونسخ خارج الجهاز |
| متوسط | لا توجد بعد إدارة تحديثات موقعة أو آلية تحقق من سلامة حزم التحديث | اعتماد تحديثات موثوقة وموقعة قبل التوزيع التجاري |

## قرار المراجعة

- لا يوجد في هذه المراجعة ما يبرر وصف الإصدار الحالي بأنه آمن أو جاهز للبيع.
- النواة الحالية مناسبة لاستكمال البناء والاختبار فقط.
- لا تُستخدم قاعدة البيانات الحالية لتسجيل عمليات منشأة حقيقية أو تشغيل نقطة بيع فعلية.
- يجب إغلاق المخاطر الحرجة والمرتفعة ضمن مراحلها الوظيفية، وإعادة مراجعتها باختبارات مستقلة قبل التسليم النهائي.

## حدود الإثبات

هذه مراجعة مصدر برمجي واختبارات آلية؛ لا تمثل اختبار اختراق، ولا مراجعة تبعيات كاملة، ولا اختباراً على جهاز عميل فعلي.

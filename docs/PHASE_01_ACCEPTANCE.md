# المرحلة الأولى — التأسيس التقني والمعماري

الحالة: **قيد التنفيذ — غير مغلقة**.

## نطاق القبول

- [x] مستودع تطوير مستقل وفرع عمل محفوظ.
- [x] هيكل حزمة Python وتعريف الاعتماديات ونقطة تشغيل.
- [x] طبقات أولية منفصلة للواجهة والخدمات والمجال والبيانات.
- [x] واجهة عربية من اليمين إلى اليسار تعرض الأصناف من قاعدة البيانات.
- [x] قواعد تسعير مالية باستخدام Decimal.
- [x] مخطط أولي موثق وقاعدة SQLite محلية.
- [x] ترحيل قاعدة البيانات بإصدارات Alembic بدلاً من إنشاء الجداول عند كل تشغيل.
- [x] اختبارات آلية أولية للتسعير والمبيعات والأصناف والتهيئة والواجهة.
- [ ] نجاح فحص Ruff بعد إصلاحات lint الأخيرة.
- [ ] نجاح كامل لاختبارات pytest بعد إضافة الترحيلات واختبارات الواجهة.
- [ ] تشغيل فعلي على Windows 10/11 والتحقق من فتح الواجهة والتعامل مع قاعدة البيانات.
- [ ] التحقق من أن التثبيت/الحزمة النهائية تتضمن ملفات الترحيل.
- [ ] إنشاء نقطة استعادة موثقة والتحقق من الاستعادة فعلياً.

## أدلة الفحص

- أول تشغيل موثق لـ GitHub Actions نجح في تثبيت الاعتماديات، لكنه فشل في خطوة Ruff؛ لذلك لم تبدأ pytest في ذلك التشغيل.
- عولجت مخالفات Ruff التي ظهرت في السجل، وأعيد تنظيم النماذج والاستيرادات ومعالجة الأخطاء.
- أضيفت اختبارات ترحيل وتهيئة قاعدة البيانات واختبارات خدمات الأصناف والواجهة.
- لم تتوفر بعد نتيجة موثقة لتشغيل CI على آخر تعديل، ولم يُجر تشغيل محلي على Windows في هذه المرحلة.

## شروط الإغلاق

لا تُغلق المرحلة حتى تظهر نتيجة CI خضراء على آخر commit، وتُنفذ اختبارات Windows الفعلية، ويُوثق اختبار النسخ والاستعادة. وجود ملفات الاختبار وحده لا يعد دليلاً على نجاحها.

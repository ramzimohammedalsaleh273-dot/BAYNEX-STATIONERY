# BAYNEX STATIONERY

نظام مكتبي عربي RTL لإدارة القرطاسيات والمكتبات ومراكز الطباعة والخدمات المكتبية. التطبيق مبني على PySide6 وSQLAlchemy وSQLite وترحيلات Alembic، ويعمل محلياً بعد تجهيز الاعتماديات.

> **الحالة:** يحتوي فرع العمل على الأصناف والمخزون والمبيعات ونقطة البيع والمشتريات ومرتجعات المشتريات والمحاسبة والخزينة ودفاتر الأطراف. اجتاز الالتزام `e2cc00ac51a5147f418224eef297da097bce9db5` اختبارات Windows الآلية: **101 اختبار ناجح**، وفحص Ruff، وفحص مشغل Windows، وبناء Wheel وتثبيته واختباره في مسار معزول. لا تزال تجربة القبول اليدوي على جهاز المستخدم والأجهزة الطرفية مطلوبة قبل الاستخدام التجاري.

## المتطلبات

- Windows 10/11.
- Python 3.11 أو أحدث.
- اتصال إنترنت عند التثبيت الأول لتنزيل الحزم؛ التشغيل بعد تثبيت الحزم محلي.

## التشغيل على Windows

1. فك ضغط الملف.
2. افتح مجلد المشروع الناتج.
3. انقر بزر الفأرة الأيمن داخل المجلد واختر فتح PowerShell.
4. نفّذ:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_windows.ps1
```

ينشئ المشغّل بيئة Python افتراضية داخل المجلد، ويثبت المتطلبات، ثم يشغّل التطبيق. يلزم اتصال إنترنت في أول تثبيت.

أو بعد تثبيت المتطلبات يدوياً:

```powershell
.\.venv\Scripts\python.exe main.py
```

## حدود النسخة

- لا تزال إدارة المستخدمين والصلاحيات الشاملة والفترات المالية والموارد البشرية والأصول الثابتة والتقارير المتقدمة خارج النطاق المنفذ.
- يلزم قبول يدوي على جهاز Windows المستهدف، وفحص الطابعة والماسح والأجهزة الطرفية قبل الاستخدام التجاري.
- النسخ الاحتياطي والاستعادة والطباعة والإصدار النهائي تحتاج إلى اختبارات قبول تشغيلية موثقة.
- قاعدة SQLite مهيأة حالياً للاستخدام المحلي على جهاز واحد، وليست قاعدة خادم متعددة المستخدمين.

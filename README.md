# BAYNEX STATIONERY

نظام مكتبي عربي لإدارة القرطاسيات والمكتبات ومراكز الطباعة والخدمات المكتبية. الهدف هو بناء منتج مستقل تجاري قابل للعمل دون اتصال بالإنترنت، مع فصل واجهة المستخدم عن منطق الأعمال والبيانات.

> **الحالة الحالية: تأسيس تقني أولي فقط.** ليس نظاماً تجارياً جاهزاً، ولا يحتوي بعد على نقطة بيع أو محاسبة متكاملة أو دورة مخزون كاملة.

## المتطلبات
- Windows 10/11 (التطوير الحالي باستخدام Python).
- Python 3.11 أو أحدث.
- اتصال إنترنت لتنزيل حزم التطوير أول مرة؛ التشغيل بعد التثبيت محلي.

## تشغيل نسخة التطوير

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python main.py
```

إذا منع PowerShell تفعيل البيئة، يمكن تشغيل:
```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe main.py
```

## تشغيل نسخة Windows من المصدر

بعد تنزيل المشروع وتثبيت Python 3.11 أو أحدث، افتح PowerShell داخل مجلد المشروع وشغّل:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_windows.ps1
```

يقوم السكربت بإنشاء بيئة Python افتراضية وتثبيت الاعتماديات ثم تشغيل التطبيق. يحتاج اتصال إنترنت عند التثبيت الأول لتنزيل المكتبات؛ هذا ليس ملف EXE مستقلاً بعد.

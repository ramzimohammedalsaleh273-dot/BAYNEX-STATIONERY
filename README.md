# BAYNEX STATIONERY

نظام مكتبي عربي لإدارة القرطاسيات والمكتبات ومراكز الطباعة والخدمات المكتبية. الهدف هو بناء منتج مستقل تجاري قابل للعمل دون اتصال بالإنترنت، مع فصل واجهة المستخدم عن منطق الأعمال والبيانات.

> **الحالة الحالية:** المرحلة الأولى والثانية مقبولتان، وتنفيذ المرحلة الثالثة (المستودعات ودفتر المخزون والجرد والتحويلات) مكتمل آلياً ويخضع لاختبار Windows اليدوي النهائي. ليس النظام التجاري النهائي ولا يعتبر جاهزاً للبيع أو لإدارة أموال العملاء.

## المتطلبات
- Windows 10/11 (التطوير الحالي باستخدام Python).
- Python 3.11 أو أحدث.
- اتصال إنترنت لتنزيل حزم التطوير أول مرة؛ التشغيل بعد التثبيت محلي.

## التشغيل السريع على Windows

من داخل مجلد المشروع بعد تجهيز بيئة Python:

```powershell
.\.venv\Scripts\python.exe main.py
```

إذا لم تكن البيئة والحزم مثبتة بعد، شغّل:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_windows.ps1
```

يحتاج التثبيت الأول اتصال إنترنت لتنزيل المكتبات؛ هذا ليس ملف EXE مستقلاً بعد.

## البيانات
قاعدة البيانات المحلية تنشأ تلقائياً عند التشغيل الأول وتبدأ فارغة. ترحيل المرحلة الثالثة يحافظ على الأرصدة والحركات التاريخية الموجودة عند الترقية. لا توجد بيانات منشأة فعلية أو بيانات أصناف تجارية حقيقية مرفقة. أدخل بيانات العميل الفعلية بعد التحقق منها، ولا تستخدم بيانات العرض باعتبارها بيانات حقيقية.

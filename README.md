# BAYNEX STATIONERY

نظام مكتبي عربي RTL لإدارة القرطاسيات والمكتبات ومراكز الطباعة والخدمات المكتبية. التطبيق Offline-first بعد تثبيت متطلباته، ويستخدم PySide6 وSQLAlchemy وSQLite وترحيلات Alembic.

> **الحالة:** هذا الفرع يحتوي سلسلة التنفيذ حتى المرحلة التاسعة: الأصناف والمخزون والمبيعات ونقطة البيع والمشتريات والمحاسبة والخزينة. اجتازت آخر نسخة بوابات CI على Windows، لكن النظام ما زال بحاجة إلى قبول يدوي وتشغيل تجريبي قبل الاستخدام التجاري، وليس إصداراً إنتاجياً نهائياً.

## المتطلبات

- Windows 10/11.
- Python 3.11 أو أحدث.
- اتصال إنترنت عند التثبيت الأول لتنزيل الحزم؛ التشغيل بعد تثبيت الحزم محلي.

## التشغيل السريع على Windows

من داخل مجلد المشروع:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_windows.ps1
```

أو بعد تثبيت المتطلبات:

```powershell
.\.venv\Scripts\python.exe main.py
```

## التحقق والاختبارات

```powershell
python -m ruff check .
python -m pytest
```

## الوحدات الموجودة

- دليل الأصناف والتصنيفات والوحدات والباركود وأسعار التجزئة والجملة.
- المستودعات ودفتر حركات المخزون والجرد والتحويلات.
- فواتير المبيعات وشاشة POS والمرتجعات والدفعات.
- الموردون وفواتير المشتريات واستلام المخزون.
- دليل الحسابات وقيود اليومية وميزان المراجعة وكشف الحساب.
- الصناديق والبنوك وسندات القبض والصرف والتحويل الداخلي.

## حدود النسخة

- قيود المبيعات والمشتريات التلقائية إلى الأستاذ العام، ودفاتر العملاء والموردين الفرعية، والتسويات البنكية المتقدمة لم تكتمل.
- المستخدمون والصلاحيات والنسخ الاحتياطي والاستعادة والطباعة الحرارية والمثبت EXE والتحديثات ما زالت بحاجة إلى تنفيذ.
- قاعدة SQLite مصممة حالياً للاستخدام المحلي على جهاز واحد، وليست قاعدة خادم متعددة المستخدمين.
- لا تستخدم النظام لتسجيل عمليات تجارية حقيقية قبل القبول اليدوي وإغلاق بوابات الجودة.

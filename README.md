# BAYNEX STATIONERY

نظام مكتبي عربي RTL لإدارة القرطاسيات والمكتبات ومراكز الطباعة والخدمات المكتبية. التطبيق مبني على PySide6 وSQLAlchemy وSQLite وترحيلات Alembic، ويعمل محلياً بعد تجهيز الاعتماديات.

> **الحالة:** يحتوي فرع العمل على الأصناف والمخزون والمبيعات ونقطة البيع والمشتريات ومرتجعات المشتريات والمحاسبة والخزينة ودفاتر الأطراف. اجتاز الالتزام `4e0b98a` اختبارات Windows الآلية (100 اختباراً)، وRuff، وبناء الحزمة واختبار تثبيتها المعزول. لا تزال تجربة القبول اليدوي على جهاز المستخدم والأجهزة الطرفية مطلوبة قبل الاستخدام التجاري.

## المتطلبات

- Windows 10/11.
- Python 3.11 أو أحدث.
- اتصال إنترنت عند التثبيت الأول لتنزيل الحزم؛ التشغيل بعد تثبيت الحزم محلي.

## التشغيل على Windows

من داخل مجلد المشروع:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_windows.ps1
```

أو بعد تثبيت المتطلبات:

```powershell
.\.venv\Scripts\python.exe main.py
```

## التحقق

```powershell
python -m ruff check .
python -m pytest
```

## الوحدات الموجودة

- الأصناف والتصنيفات والوحدات والباركود وأسعار التجزئة والجملة.
- المستودعات ودفتر حركات المخزون والجرد والتحويلات.
- فواتير المبيعات ونقطة البيع والمرتجعات والتحصيل.
- الموردون وفواتير المشتريات واستلام المخزون ومرتجعات المشتريات.
- دليل الحسابات والقيود اليومية وميزان المراجعة وكشف الحساب.
- الصناديق والبنوك وسندات القبض والصرف والتحويل الداخلي.
- دفاتر العملاء والموردين الفرعية.

## حدود النسخة

- لا تزال إدارة المستخدمين والصلاحيات الشاملة والفترات المالية والموارد البشرية والأصول الثابتة والتقارير المتقدمة خارج النطاق المنفذ.
- يلزم قبول يدوي على جهاز Windows المستهدف، وفحص الطابعة والماسح والأجهزة الطرفية قبل الاستخدام التجاري.
- النسخ الاحتياطي والاستعادة والطباعة والإصدار النهائي تحتاج إلى اختبارات قبول تشغيلية موثقة.
- قاعدة SQLite مهيأة حالياً للاستخدام المحلي على جهاز واحد، وليست قاعدة خادم متعددة المستخدمين.
